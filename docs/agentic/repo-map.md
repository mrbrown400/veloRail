# VeloRail Repo Map

Generated by `npm run agent:repo-map`.

## App Shape

- Entry path: `index.html -> src/main.tsx -> src/App.tsx`.
- Frontend: React, TypeScript, Vite, Zustand, React Query.
- Map runtime: Google Maps JavaScript APIs through `@googlemaps/js-api-loader` and `@react-google-maps/api`.
- Routing/data focus: car-free route planning, future transit overlays, visionary/freight/nationalized scenarios, GTFS ingestion, and scoring.

## Agent Workflow

- Start from `AGENTS.md` and the relevant `.agents/skills/*/SKILL.md` file.
- Use Linear for active task state and GitHub for code review.
- Use `npm run task:gate -- <task-id> --explain` before closing work.
- Browser-facing changes require `npm run test:browser:required` with a task tag or smoke tag.
